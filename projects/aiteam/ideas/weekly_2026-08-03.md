## Add per-call input/output token logging to asbestos-auditor and ssg-auditor before next synth cycle

**Score:** 4.0 · **Build:** 1.5h · **Impact:** `medium` · **Slug:** `asbestos-auditor-token-split-logging`

**Signal:** `diagnose.b_top_cost_agents_7d[0] and [2]; diagnose.g_verdict_pass_rate_14d[0]`

ssg-auditor and asbestos-auditor together cost $29.87/week across 60 calls (diagnose.b_top_cost_agents_7d[0] and [2]: $19.47 + $10.41), the two most expensive agents in the fleet this week and every week for the past three runs. No new LLM calls, no new tables — one JSON field addition per auditor script.

Cost: near-zero marginal (the token counts are already in the API response object, currently discarded). Recovers the ability to answer whether the $29.87/week is input-cost-driven (fixable by trimming prompt context) or output-cost-driven (fixable by capping rationale length) — a fix that, at the historical fleet mean of $0.061/call, could cut this pair's spend by 40-60% (~$12-18/month) once the actual driver is known.

Downside: if the token split shows the cost is inherent to the content length being audited (not wasteful), this yields diagnostic clarity but no savings — a sunk 90 minutes with a null result.
